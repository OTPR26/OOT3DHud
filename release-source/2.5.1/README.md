# Ocarina ReFramed 2.5.1 source

Each regional directory contains its build instructions and expected patch checksum. Build locally with devkitPro/devkitARM and Python 3. Preserve the included licenses and attribution notices.

The Single Screen file-selection fade was reproduced and verified corrected in Azahar on an Odin. Dual Screen input fixes pass host regression tests and all regional builds. Luma patches pass executable-buffer bounds checks; physical-console testing is unavailable and compatibility remains experimental.

No ROMs, game executables, saves, or signing material are included.
