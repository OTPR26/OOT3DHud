# Ocarina Reframed 2.0.1 corresponding source

Single Screen code and assets are unchanged from the [2.0 source](https://github.com/OTPR26/OOT3DHud/tree/v2.0/release-source/2.0/single).
Dual Screen source is in dual/USA, dual/EUR and dual/JP. BUILD.txt records the exact flags and code.ips hash for each region. These sources also supply the experimental Luma code, paired with each region's hardware exheader.
File-level licenses and notices are preserved under each regional directory.
