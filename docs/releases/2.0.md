# Ocarina Reframed 2.0

Ocarina Reframed 2.0 is a major upgrade of Ocarina Reframed Mod for Ocarina of Time 3D. Available in both Single Screen and Dual Screen options.

## What’s new

- A unified pause screen menu designed for single-screen play
- Items, Gear, Map, Save, and Options integrated into one controller-friendly interface
- New Options Menu  with adjustable settings for:
  - HUD size
  - Free-camera distance and direction
  - Movement speed
  - Roll speed
  - Roll recovery
- Improved menu transitions, page navigation, item previews, and controller assignments
- Refined file-selection presentation and corrected visual seams
- Updated Game Over and longer ocarina-song handling
- Modern gameplay HUD with a controller-neutral layout
- Native assets included, texture pack is not required

## Regional support

Ocarina Reframed 2.0 supports:

- North America — Rev 1
- Europe — Rev 1, English
- Japan — Rev 1

Taiwan and Korea coming soon.
