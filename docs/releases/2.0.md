# Ocarina Reframed 2.0

Ocarina Reframed 2.0 is a major upgrade to the Ocarina Reframed mod for Ocarina of Time 3D. It is available in both Single Screen and Dual Screen editions.

## What's new

- A unified pause menu designed for single-screen play
- Items, Gear, Map, Save, and Options integrated into one controller-friendly interface in the Single Screen edition
- A new Options menu with adjustable settings for:
  - HUD size
  - Free-camera distance and direction
  - Movement speed
  - Roll speed
  - Roll recovery
- Improved menu transitions, page navigation, item previews, and controller assignments
- Refined title-screen and file-selection presentation with corrected visual seams
- Improved Game Over presentation and support for longer ocarina songs
- A modern gameplay HUD with a controller-neutral layout
- Native assets included—no texture pack required

## Editions

- **Single Screen** includes the unified pause-screen experience.
- **Dual Screen** retains the traditional two-screen layout while adding the new upper-screen Options menu and the updated title-screen and file-selection design.

## Luma3DS build

An updated experimental Dual Screen Luma3DS build is included for North
America Rev 1, Europe Rev 1 English, and Japan Rev 1. It uses hardware-target
memory and input handling informed by physical-console feedback, including safer
controller-shortcut injection that does not write into protected HID shared
memory.

Use it only with a clean, unmodified game matching the listed region and
revision. Enable game patching in Luma3DS, and do not combine it with a patched
ROM, another code mod, or a plugin. Physical-console compatibility remains
experimental.

## Regional support

Ocarina Reframed 2.0 supports:

- North America — Rev 1
- Europe — Rev 1, English
- Japan — Rev 1

Taiwan and Korea support is coming soon.

## Downloads and installation

Choose one edition and installation method:

- `Ocarina-Reframed-2.0-Single-Screen-Mods.zip`
- `Ocarina-Reframed-2.0-Single-Screen-ROM-Patches.zip`
- `Ocarina-Reframed-2.0-Dual-Screen-Mods.zip`
- `Ocarina-Reframed-2.0-Dual-Screen-ROM-Patches.zip`
- `Ocarina-Reframed-2.0-Luma-Mods-Experimental.zip`

Each archive contains North America, Europe, and Japan folders. Keep your saves.
Mod users should replace the existing regional mod folder; ROM Patch users
should apply the patch to the matching clean original ROM and disable external
mod overrides. Do not apply a new patch over a previously patched ROM.

See [installation directions](https://github.com/OTPR26/OOT3DHud/blob/main/INSTALL.md),
[ROM checksums](https://github.com/OTPR26/OOT3DHud/blob/main/docs/releases/2.0-checksums.md),
and [corresponding source](https://github.com/OTPR26/OOT3DHud/tree/main/release-source/2.0).

## Verification scope

Single Screen uses the accepted regional candidates. All six regional/edition
code builds and ROM-patch reconstructions were checked, and the final archives
were extracted and verified. The new Dual Screen Options adapter passed host
tests for entry, navigation, failed settings writes, immediate exit, held-button
isolation, and native touch handling. Its new presentation has not had a fresh
gameplay test. Luma builds pass loader-memory and hook checks but remain
unconfirmed on physical consoles. Optional texture packs, arbitrary randomized
ROMs, and all emulator/platform combinations are not covered by these checks.
