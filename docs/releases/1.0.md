## Rev 1 — Korean Single Screen hotfix

Restores the Save and Options controls on the main screen in the Korean
Single Screen edition. Fixed in both Mod and ROM Patch downloads and tested
on Azahar. Other regions and Dual Screen mod/patch payloads are unchanged.

Mod users: replace the Korean mod folder with the updated download.
ROM Patch users: apply the updated patch to your original clean Korean ROM,
not to an already-patched ROM. Keep your saves and original ROM.

**Two ways to experience Ocarina of Time 3D:**

- **Single Screen:** redesigned file selection, Items, Gear, Map, and Songs on
  the main screen, with item previews, descriptions, and live controller assignments.
- **Dual Screen:** the original two-screen experience with the modern HUD and free camera.

Both include a controller-neutral diamond.

Four downloads: Single Screen or Dual Screen, each available as **Mod** or **ROM Patch**, with all five regional folders inside.

Choose an installation method, then open the folder for your game's region. Use the included README and the [ROM checksums on GitHub](https://github.com/OTPR26/OOT3DHud/blob/main/docs/releases/1.0-checksums.md). No game ROMs or save files are included.
