# Ocarina Reframed 1.0

Two ways to experience Ocarina of Time 3D:

- **Single Screen:** redesigned file selection, Items, Gear, Map, and Songs on
  the main screen, with item previews, descriptions, and live controller assignments.
- **Dual Screen:** the original two-screen experience with the modern HUD and free camera.

Both include a controller-neutral diamond.

Four downloads: Single Screen or Dual Screen, each available as **Mod** or
**ROM Patch**, with all five regional folders inside.

| | Emulator mod | ROM patch |
| --- | --- | --- |
| Single Screen | `Ocarina-Reframed-1.0-Single-Screen-Mods.zip` | `Ocarina-Reframed-1.0-Single-Screen-ROM-Patches.zip` |
| Dual Screen | `Ocarina-Reframed-1.0-Dual-Screen-Mods.zip` | `Ocarina-Reframed-1.0-Dual-Screen-ROM-Patches.zip` |

Choose one edition and one installation method, then open the folder for your
game's region. Use the included README and source checksums. No game ROMs or
save files are included.

## Mod installation

1. Extract the ZIP and choose your game's region.
2. Find the user-data folder for your emulator.
3. Move any existing regional mod contents out of `load/mods`.
4. Merge the included regional `load` contents into the user-data folder.
5. Launch the supported ROM normally.

## ROM-patch installation

1. Choose your region and check your original ROM against `SOURCE.txt`.
2. Apply `patch.xdelta` using an xdelta3-compatible patcher.
3. Verify the patched ROM's output checksum.
4. Disable or remove any existing HUD-related mod, then launch the patched ROM.

See the included README for backups, exact checksum requirements, and mod conflicts.

## Compatibility notes

The selected builds have scoped AYN Azahar Plus checks in both mod and
ROM-patched form for all five regions, with custom textures disabled. The
North American, European, and Japanese ROM patches target the tested Rev 1
sources; Taiwan and Korea target the exact supplied regional sources. Every
patch requires the exact input checksum listed in its folder.

European runtime checks used English; Taiwan checks used Simplified Chinese.
These checks do not establish support for every language, revision, platform,
HUD scale, or optional texture pack. Final-build Windows Azahar/RetroArch and optional texture-pack combinations
have not all been retested; those combinations are not covered by these checks.

Optional texture packs are separate. Do not install another project's bundled
code mod over Ocarina Reframed. Randomizer combinations are not yet validated:
these clean-ROM patches must not be applied to an arbitrary randomized ROM.
