# Ocarina Reframed 1.0

Two ways to experience Ocarina of Time 3D:

- **Single Screen:** redesigned file selection, Items, Gear, Map, and Songs on
  the main screen, with item previews, descriptions, and live controller assignments.
- **Dual Screen:** the original two-screen experience with the modern HUD and free camera.

Both include a controller-neutral diamond.

Four downloads: Single Screen or Dual Screen, each available as **Mod** or **ROM Patch**, with all five regional folders inside.


Choose one edition and one installation method, then open the folder for your
game's region. Use the included README and the [ROM checksums on GitHub](https://github.com/OTPR26/OOT3DHud/blob/main/docs/releases/1.0-checksums.md). No game ROMs or
save files are included.
