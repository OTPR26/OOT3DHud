## Ocarina Reframed 1.1

### Game Over fixes

- Restores the Game Over dialogue on the main screen in Single Screen mode, with smaller Save / Don't Save and Continue / Quit choices and no leather backdrop.
- Fixes the corrupted Game Over heading with the bundled North American English HUD artwork, in both Single Screen and Dual Screen.
- Preserves native Game Over input while clearing interrupted shortcut/menu state.

Includes the previous Korean save-menu and longer ocarina-song fixes.

### Downloads

Choose Single Screen or Dual Screen, then Mod or ROM Patch. Each of the four ZIPs contains North America, Europe, Japan, Taiwan, and Korea, plus one simple README. A 4K texture pack is not required.

Mod users: replace the existing regional mod folder. ROM Patch users: apply the new patch to a clean original ROM, not a previously patched ROM. Keep your saves.

### Verification

The North American Single Screen fix was confirmed in gameplay on Windows RetroArch. Regional native addresses and state handling were checked, all five Single Screen builds were rebuilt, and every changed ROM patch passed an apply-and-checksum round trip. The other regional Game Over screens and the Dual Screen heading correction have not had new gameplay testing for this release.

Other Dual Screen regional payloads are unchanged. `Luma-Mods-Experimental.zip` contains the updated 1.1 experimental Dual Screen mods for USA Rev 1, Europe Rev 1, and Taiwan. Includes the North American English Game Over heading fix, rebuilt hardware-target code, and preserved Luma-specific headers. Static checks passed; physical 3DS testing is still required. Single Screen menu-layout changes do not apply.

The separately reported intermittent D-pad / Start / Select unresponsiveness remains under investigation and is not claimed fixed here.
