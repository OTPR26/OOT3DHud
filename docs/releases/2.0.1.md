# Ocarina Reframed 2.0.1

This update fixes the Dual Screen file selection regression reported in [issue #14](https://github.com/OTPR26/OOT3DHud/issues/14). The file list appears only on the lower screen, and Link is visible on the upper screen again.

Single Screen builds are unchanged from 2.0. The corrected Dual Screen builds and experimental Luma builds cover North America Rev 1, Europe Rev 1 English, and Japan Rev 1. Taiwan and Korea remain planned for later.

The North America Dual Screen fix was checked in Azahar at file selection, during gameplay, and in the upper-screen Options menu. Europe and Japan passed build and package checks. Physical-console Luma compatibility remains experimental.

For the complete feature list, see the [agreed 2.0 release notes](https://github.com/OTPR26/OOT3DHud/releases/tag/v2.0). Installation directions and clean-ROM checksums are in this repository.
