Ocarina Reframed features

A modern single-screen HUD for Ocarina of Time 3D.

Ocarina Reframed moves touch-screen essentials into the main view and onto physical controls while preserving the original game’s progression, balance, inventory rules, and save data.

Native presentation. Modern control.

The interface reads live game state and renders through OoT3D’s native HUD. Equipped items, action text, ammo, health, magic, and rupees remain synchronized with the game instead of being simulated by an external overlay.

Live single-screen HUD

See action prompts, equipped items, ammo, health, magic, rupees, and the minimap together without relying on the original touch-screen layout.

Physical item shortcuts

Use the D-pad for Item I, Item II, Navi/View, and the Ocarina. The Select button opens the Items screen.

C-stick free camera

Look around freely with adjustable sensitivity and inversion controls, based on Roberto-Nessy’s standalone OoT3D free-camera work.

Adjustable HUD scale

Cycle among 75%, 100%, 125%, and hidden HUD modes with L + R + ZR.

Improved fonts

Dialogue, prompts, and file names are clearer in the USA and Europe releases while preserving the game’s visual character.

Regional support

Supports USA Rev 0 and Rev 1, Europe Rev 1, Japan Rev 1, Taiwan Rev 1, and Korea Rev 1, including Normal and Master Quest.

Texture-pack friendly

Adds one dedicated HUD texture and is designed to coexist with existing Ocarina of Time 3D texture packs.
