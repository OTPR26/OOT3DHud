Ocarina ReframedTwo ways to experience Ocarina of Time 3D.

A high-resolution HUD and C-stick free camera mod for Ocarina of Time 3D. Inspired by Project Restoration’s modern controller layout, every element is fed by live game state and rendered through OoT3D’s native interface.

Single Screen

Redesigned file selection, Items, Gear, Map, and Songs on the main screen, with item previews, descriptions, and live controller assignments.

Dual Screen

The original two-screen experience with the modern HUD and free camera. Keep the familiar layout on dual-screen devices.

FAQ

A few things
worth knowing.

Does this change Ocarina of Time’s gameplay?+

No. The project changes the HUD, physical input routing, and camera presentation. Progression, combat balance, inventory rules, save data, and the original game remain intact.

Can I use a texture pack?+

Yes. A 4K texture pack is optional: both delivery methods include the required visuals. Use only the pack’s texture directory, not its bundled code mod.

Which version(s) are supported?+

The current release supports USA Rev 1, Europe Rev 1, Japan Rev 1, Taiwan, and Korea. Normal and Master Quest are supported. Match the exact supported ROM using the ROM checksums.
