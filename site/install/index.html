Mod installation

  1. Extract the ZIP and choose your game’s region.
  2. Close the game and find your emulator’s user-data folder.
  3. Move the old mod folder for this game out of load/mods. Keep a backup.
  4. Merge the included load folder into the user-data folder.
  5. Launch your supported ROM normally.

ROM-patch installation

  1. Extract the ZIP and choose your game’s region.
  2. Check your clean ROM against the linked source checksum.
  3. Apply patch.xdelta with an xdelta3-compatible patcher, such as Rom Patcher JS.
  4. Save as a new ROM and verify its output checksum. Keep your original.
  5. Disable existing HUD-related mods, then launch the patched ROM.

Use the user-data folder for the emulator you actually run; standalone Azahar and RetroArch may use different folders. Restart normally instead of loading an old save state. Do not move or delete saves.

Using a texture pack? Install its texture directory only, not its bundled code mod. Do not combine competing code patches or assume compatibility with Randomizer outputs. Full compatibility guidance ↗
