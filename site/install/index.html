Installation guide

Install Ocarina Reframed for Ocarina of Time 3D.

Choose either the emulator mod files or the regional xdelta patch. Verify your game region and revision before downloading; patches are not interchangeable.

Three steps.

The release supports USA Rev 0 and Rev 1, Europe Rev 1, Japan Rev 1, Taiwan Rev 1, and Korea Rev 1. Normal and Master Quest use the same game file.

1. Download

Open the latest release and choose the archive or xdelta patch matching your game’s exact region and revision.

2. Install or patch

For Azahar/Citra, merge the included load folder into the emulator’s user folder. For a ROM, apply the matching xdelta with Rom Patcher JS ↗.

3. Restart

Fully close and restart the emulator, then launch the game normally. Do not resume an older save state after installing or updating the mod.
